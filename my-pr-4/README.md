## 🚀 Getting Started

### 1. Clone the repository

git clone [https://github.com/your-username/medcare-pharmacy.git](https://github.com/your-username/medcare-pharmacy.git)
cd medcare-pharmacy
2. Install dependencies
Bash
npm install
3. Start the Mock Server
Ensure you have the db.json file in your root and run:

Bash
npx json-server --watch db.json --port 5000
4. Run the Application
Bash
npm run dev
